# NOIR — portfolio edition

Независимый статический проект. HTML, CSS, JavaScript, без сборки и сервера. Товары, отзывы, кейсы и показатели — иллюстративный контент для портфолио, не реальные коммерческие заявления.

## Публикация за 5 минут

- **Netlify:** Add new site → Deploy manually → перетащите папку проекта с index.html в корне. Сайт сразу получит публичный HTTPS URL.
- **GitHub Pages:** загрузите index.html, styles.css, script.js в корень нового репозитория. Settings → Pages → Deploy from branch → main / root → Save.
- **Vercel:** импортируйте Git-репозиторий, Framework Preset: Other, Build Command: пусто, Output Directory: `.` → Deploy.

Для этих хостингов достаточно трёх основных файлов. README можно оставить. `.openai` и `dist` нужны только публикации Sites. Ссылки ./styles.css и ./script.js намеренно относительные, чтобы работали и подпапки GitHub Pages. Все внешние ресурсы — абсолютные HTTPS CDN URL. Замените og:url на окончательный домен.

## Возможности

12 позиций, фильтры и модальные окна. В магазине и ресторане — сортировка цен, корзина с количеством, удалением и экспортом состава заказа. NOIR: выбор размера в быстром просмотре (быстрый плюс добавляет M). Тема и корзина сохраняются в localStorage отдельно для каждого проекта. Заказ — демо, оплаты и отправки ресторану нет. Форма валидирует поля и открывает mailto на zadirozhniizahar@gmail.com. Посетитель самостоятельно отправляет письмо в своей почтовой программе. Если программа не настроена, адрес показан в интерфейсе. Об этом явно сообщается посетителю.

## Настоящие заявки

На Netlify добавьте форме `name="contact" method="POST" data-netlify="true"` и скрытое поле `<input type="hidden" name="form-name" value="contact">`. Удалите в script.js обработчик `document.querySelectorAll('form').forEach(...)` под комментарием Validated demo form. Опубликуйте заново: Netlify обнаружит HTML-форму и покажет заявки в Forms. Для Pages/Vercel можно задать `action` формы на ваш Formspree endpoint, также удалив демонстрационный обработчик. Перед приёмом реальных персональных данных добавьте собственную политику конфиденциальности.

## Редактирование

Массив config.items в начале script.js содержит названия, категории, цены, изображения и описания. Фото Unsplash иллюстративные; замените их точными фото продукции. Проверьте состав и аллергены блюд, настоящую зону доставки, условия акции. Таймер FEAST истекает через сутки после первого посещения, не сбрасывается при обновлении страницы. Кейсы и показатели LUMEN замените проверенными данными до коммерческого запуска. Контакты и соцсети подключайте к настоящим аккаунтам владельца.

## Анимации и доступность

AOS, GSAP и Swiper через CDN; Google Fonts. Lazy-loading изображений, приоритет hero, SEO/OG, SVG favicon, нативные dialog с Escape и удержанием фокуса, видимый фокус клавиатуры. Учитывается prefers-reduced-motion. Основной каталог работает при недоступности CDN анимаций. Внешним фото и библиотекам нужен интернет; для автономной версии скачайте их и измените ссылки.
